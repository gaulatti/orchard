styles, fonts and collector/client hashes to 94 layouts, 12 scrollbar paint
states, 106 original full-client PNGs and 16 input histories. Final independent
captures match all 107 receipt/PNG files. The collector removes Playwright's
headless `--hide-scrollbars` switch so reserved gutters and scrollbar paint are
present. Earlier zero-gutter exploratory captures are superseded.

The viewport/offset model matches source box geometry and hidden-axis/RTL
clamping. `verify-scroll-area-reference.mjs` decodes original images and verifies
hover/rest pixels and the minimum thumb. The separate hidden native primitive
auditor checks six orientation/direction templates plus four stock alternatives,
original ownership, source gutter/thumb bounds, actual native PNG pixels and
background guards. It does not claim a ScrollArea implementation or source theme
paint. See [the contract and remaining work](../../docs/scroll-area-reference.md).

# Select / HeaderSelect

`Select.json` binds both frozen component sources, their styles/dependencies,
installed module versions and bundled fonts to 292 closed states, 32 open states,
92 complete original PNGs and eight genuine browser request sequences. Regenerate
with `scripts/reference/capture-select.cjs` and its adjacent client. The ordinary
empty-value case without an empty option preserves Radix internal history;
HeaderSelect inserts an empty placeholder and remains controlled. Four closed
autofocus cases carry focused source paint. Invisible native checks verify their
geometry while explicitly deferring focus and focused presentation. They never
open a popup or send input. The original PNGs are retained without transformations.

# Data Table surface paint

`DataTablePaintCounterexamples.json` binds two unchanged native PNGs to the
original report, host and library hashes. The first shows the previous generic
black border/light-sand header recipe. The second preserves the 934-pixel RTL
capture produced by mirrored invisible shadow masks. The paint negative gate
rejects the former against current surface pixels and the latter's
wrong viewport dimensions. Normal paint checks retain a one-channel pixel
tolerance and the full one-DIP geometry gate, inspect both composition layers,
and assert checkbox opacity/brush endpoints. Composition graph checks do not
establish shadow raster parity or complete component acceptance.

`DataTablePerformanceLateObservation.json` and its unchanged PNG preserve the
first rejected paginated benchmark observation. The former harness attached
`Loaded` handlers after rows were loaded, then observed false `IsLoaded` values.
Separate early/late listener diagnostics isolated that observer effect. The
corrected workload observes unloads outside timing and keeps its row-ready gate;
its negative auditor rejects the retained original state. This is a harness
counterexample, not a claim of a component defect.

`DataTableFilterPlan.json` records eight supplemental pinned-component cases and
24 original PNGs: absent columns, boolean-only eligibility, an active boolean
column filter and hidden eligible columns in both themes. Two independent
captures reproduce every state and PNG. Its collector reuses the hash-verified
original bundle and CSS; it does not change the component implementation.
`DataTableFilterPlanCounterexamples.json` binds six actual rejected native
states/PNGs to their prior host and library. Their global queries incorrectly
removed every row. `DataTableFilterLineBoxCounterexamples.json` separately binds
the two original empty-action captures whose rows were four DIPs too short.
The native negative gate checks all eight original images and rejects the
corresponding row results or geometry without changing the one-DIP tolerance.
