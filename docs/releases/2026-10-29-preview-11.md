# Orchard 0.1.0-preview.20261029.11

This preview accepts Icon Badge on x64. The published-build catalog passes six
size/variant combinations and empty, scalar, named and interactive content in
Light and Dark. Physical child clicks and Tab focus pass in both themes, with
consumer content and focus retained across live updates and remounts. The
matching independent NuGet consumer compiles and runs without warnings; its
native 150% scale fixture passes fourteen cases, including visible child
overflow outside the badge. Icon Badge is static, and the catalog passed with
Windows animations already disabled. No OS setting was changed.

## Accepted components

- Brand Mark
- Context Menu
- Error State
- Icon Badge
- Kbd
- Label
- Loading Spinner
- Progress
- Separator
- Status Badge

The fixed 112-entry inventory has **10 accepted** and 102 not yet accepted.
These are entry counts, not a completion percentage. Monitoring and Editorial
remain fictional local-data component demos. ARM64 catalog and independent
consumer builds pass; native ARM64 runtime is unverified. Raster/pixel parity
is not a release gate.

The package verifier now clears its generated consumer app between x64 and
ARM64 builds. This prevents a stale ARM64 Win2D DLL from being left beside an
x64 apphost; the clean `.11` x64 consumer runtime and ARM64 compile both pass.
