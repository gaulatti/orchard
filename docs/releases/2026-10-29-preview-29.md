# Orchard 0.1.0-preview.20261029.29

This preview adds Breadcrumb and Skeleton to the x64 accepted list. Both passed
the five component checks: applicable Light/Dark states, native input and focus,
150% layout without clipping, reduced motion, and independent NuGet consumer
compilation. The extracted, package-matched x64 catalog passed both focused
routes. Breadcrumb passed eight native 150% cases and Skeleton passed four.

The fixed 112-entry inventory has **33 accepted** and 79 not yet accepted.
These are entry counts, not a completion percentage. Monitoring and Editorial
remain fictional local-data component demos. ARM64 is build-only; native ARM64
runtime is unverified. Raster/pixel parity is not a release gate.
