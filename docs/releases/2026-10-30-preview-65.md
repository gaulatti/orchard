## X64 acceptance and package verification

Attention Surface passes the five milestone checks on the exact .65 x64
package and extracted catalog. Its 43 Light and 43 Dark states render, and
physical pointer, keyboard, focus, action, disabled, and caller-content checks
pass. Native hover reaches its endpoint with Windows animations already
disabled. The independent package consumer compiles and runs; its native 150%
fixture passes eight Article/Button layouts across both themes and 260/420 DIP
widths without clipping. The extracted catalog passes 72 fictional Monitoring
and Editorial demo checks. The library implementation is unchanged in this
release; the catalog smoke path no longer treats raster/pixel comparisons as
an acceptance gate. Earlier 498 portable and 10 Windows text tests remain
valid for the unchanged library implementation; they were not rerun for .65.

The x64 catalog archive was stream-verified for 664 files and contains the
same library bytes as the NuGet package. The ARM64 catalog builds and its
660-file archive stream-verifies; an independent ARM64 consumer compiles.
ARM64 runtime is unverified.
