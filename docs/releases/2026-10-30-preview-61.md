## Validation and artifacts

- App Shell's unchanged library implementation retains the prior independent
  consumer's 168 Light/Dark layout states and 44 ownership checks with zero
  geometry error. Its 56 source PNGs were audited, but raster parity is not
  an acceptance gate.
- The extracted .61 x64 catalog passed physical Tab, Space and pointer actions
  in Light and Dark. Header and body actions worked; the original editor and
  controls survived the offset-header layout change.
- The exact .61 NuGet package compiled and ran in an independent x64 consumer.
  Eight native 150% App Shell layouts passed across Light/Dark, two widths and
  both offset-header modes. Header, main, content, footer and visible text fit.
  The header's logical line box overhang showed no ink in the first six physical
  pixel rows. All layouts remained settled with Windows animations disabled.
- The x64 catalog ZIP was stream-verified across 664 files, and its extracted
  Orchard.dll matched the NuGet package. The extracted fictional Monitoring and
  Editorial demos passed 72 isolated checks.
- The ARM64 catalog built and its ZIP was stream-verified across 660 files.
  An independent ARM64 package consumer compiled. ARM64 runtime is unverified.
- The library implementation is unchanged. The previously passed 498 portable
  and 10 Windows text tests are reused; .61 changes catalog and package-consumer
  acceptance fixtures and documentation only.
