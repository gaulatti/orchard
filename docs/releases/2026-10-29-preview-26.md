# Orchard 0.1.0-preview.20261029.26

This preview accepts Icon Button on x64. All nine size/variant combinations
rendered in Light and Dark. The matching extracted catalog passed physical
pointer, Space, Enter, focus, disabled-action and reduced-motion pressed-state
checks. An independent NuGet consumer compiled and ran against the package;
its native 150% fixture passed all 18 Light/Dark size/variant cases without
clipping.

The fixed 112-entry inventory has **29 accepted** and 83 not yet accepted.
These are entry counts, not a completion percentage. Monitoring and Editorial
remain fictional local-data component demos. ARM64 is build-only; native ARM64
runtime is unverified. Raster/pixel parity is not a release gate.
