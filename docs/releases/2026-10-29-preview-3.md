# Orchard 0.1.0-preview.20261029.3

This preview delivers the native Context Menu modal-owner click repair and
uses the 2026-10-29 x64 milestone acceptance contract. The original native
menu presenter now receives physical item clicks while its modal owner is
active; an upper modal shields the menu until the owner resumes. The menu
retains original caller actions, focus, bindings, and dismissal behavior.

## Accepted components

- **Separator** — Light/Dark states, passive keyboard/pointer/focus semantics,
  150% scaling without clipping, static reduced-motion behavior, and candidate
  package-consumer compilation pass on x64.

The fixed inventory has 112 entries started, **1 accepted** and 111 not yet
accepted. These numbers are entry counts, not a completion percentage.
Context Menu passes the Light/Dark, input/focus, and package-consumer checks;
its 150% no-clipping and reduced-motion checks remain open, so it is not on
the accepted list. The Monitoring and Editorial screens remain fictional
component demos.

## Validation and artifacts

- Library tests: 498 passed; text tests: 10 passed on the candidate source.
- x64 package consumer: compiled with zero warnings against the candidate
  NuGet package; restored bytes match the package SHA-256
  `4a2586b23494add27d4b4fe99b12e9e1211aa3a005c34068f531e0ac325e70c9`.
- x64 native Context Menu: physical click on an item owned by an active modal
  invoked its original caller action on the package-matching DLL. Keyboard
  opening, Escape, focus, and Enter action were also verified on that DLL.
- Native Context Menu audit regressions: 23 damaged modal reports plus four
  wrong-theme samples, and 25 damaged option reports, were rejected.
- x64 catalog archive: built and stream-verified. ARM64 catalog: built with
  zero warnings and archived; **ARM64 runtime unverified**.
- Raster/pixel parity is not an acceptance gate. No new evidence folder was
  created for this milestone. GitHub Actions were not triggered by validation.
