## X64 acceptance and package verification

Select passes the five milestone checks on the exact .69 x64 package and
extracted catalog. The independent consumer covers the shared 292 Light/Dark
states, eight histories, and 58 public contracts without failure. Physical
pointer, keyboard, typeahead, outside-dismissal, caller value requests and
focus pass in both themes. The reduced-motion focus ring reaches its endpoint
within two render frames, and the independent package consumer passes four
native 150% open-menu layouts without clipping at 420/600 DIP. The consumer
compiles and runs. The extracted catalog passes 72 fictional Monitoring and
Editorial demo checks. The library implementation is unchanged from .68; the
shared fixture adds focused acceptance coverage.

The x64 catalog archive is byte-verified and contains the same library DLL as
the NuGet package. ARM64 builds and its independent consumer compiles; ARM64
runtime is unverified.
