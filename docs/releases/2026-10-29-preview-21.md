# Orchard 0.1.0-preview.20261029.21

This preview accepts Panel Layout and its Panel Column on x64. The matching
catalog passed 86 Light/Dark layouts and two native interaction sequences,
including child actions, retained editor focus and values, growth changes,
horizontal scrolling and remounts. An independent NuGet consumer compiled and
ran, and 12 native 150% Light/Dark cases passed at narrow and wide viewports.
The layout defines no animation or transition; static behavior passed with
animation effects disabled. Its deliberate horizontal overflow remains
scrollable. No OS settings were changed.

These are entry counts, not a completion percentage. Monitoring and Editorial
remain fictional local-data component demos. ARM64 is build-only; native ARM64
runtime is unverified. Raster/pixel parity is not a release gate.
