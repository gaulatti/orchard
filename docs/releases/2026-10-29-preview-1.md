# Orchard component-library preview 2026-10-29.1

`0.1.0-preview.20261029.1` packages the reusable WinUI 3 library and its
runnable x64 and ARM64 catalogs from source commit `88e85b9`. It is a preview
of the current component work, including the fictional Monitoring and
Editorial demos, rather than acceptance of the full 112-entry inventory.

The NuGet package SHA-256 is
`5ae3aa13c09b37f4a6d9a4df8d29fd352a4365802d375cc8f57575fedf889deb`.
An isolated x64 package-reference consumer restored these exact bytes, published
self-contained, and exited successfully after checking resources, fonts,
Light/Dark themes, layout and a native action. The independent ARM64 consumer
compiled with an ARM64 apphost and the same package DLL; it did not run here.
The portable and text test projects passed 498 and 10 tests respectively.

The x64 catalog ZIP SHA-256 is
`18cf2e5059a52e0f392c823675719663b1dd994dce315d7b7da0f5f02496d509`.
All 821 entries, including 114 compiled XAML fixtures, were stream-verified.
A fresh extraction contained the exact NuGet DLL. Its hidden Monitoring and
Editorial checks passed 72 cases and 589 isolation guards across both themes.
Visible physical checks passed Monitoring review in Light and Editorial edit
and dirty-decision behavior in Dark. Both captured screens were inspected.
These focused checks do not establish complete demo visual or input acceptance.

The ARM64 catalog ZIP SHA-256 is
`9fe0ff3f3b6f48db4367e36110d4a04c97354bf306593d8c887d18937fcf616b`.
Its ARM64 build passed with zero warnings or errors; all 817 ZIP entries,
including 114 compiled XAML fixtures, were stream-verified, and the archive
contains the exact NuGet DLL. Native ARM64 execution is unverified on this x64
machine. The first ARM64 `--no-restore` attempt failed because the assets file
had only an x64 target; restoring ARM64 resolved that setup error.

The active-modal-owner Context Menu still opens with keyboard and pointer but
a physical click on its visible original item does not invoke the caller
handler. The [window-hit checkpoint](../evidence/context-menu-window-hit-v1/checkpoint.json)
retains this failure. No library fix for it is claimed in this preview.
The inventory remains 112 entries started, zero accepted. Narrator and OS
contrast campaigns are outside the library goal, and no GitHub Actions run was
triggered for this qualification.

The [delivery checkpoint](../evidence/preview-20261029-1/checkpoint.json)
records local artifact paths, exact hashes, passing checks and limits. The
repository wiki remote was unavailable, so this release note lives in the
repository.
