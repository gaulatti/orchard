# Orchard 0.1.0-preview.20261029.23

This preview accepts Avatar and AvatarGroup on x64. The matching package
consumer passed 280 Light/Dark size, fallback, image and group states and 32
group/lifecycle contracts. The catalog presentation route passed, and four
native 150% Light/Dark narrow/wide cases kept initials, empty silhouettes and
overflow circles within bounds. Both controls are passive with no focus stops
or motion; the hidden consumer recorded zero focus and activation. An
independent x64 NuGet consumer compiled and ran against this package.

The fixed 112-entry inventory has **25 accepted** and 87 not yet accepted.
These are entry counts, not a completion percentage. Monitoring and Editorial
remain fictional local-data component demos. ARM64 is build-only; native ARM64
runtime is unverified. Raster/pixel parity is not a release gate.
