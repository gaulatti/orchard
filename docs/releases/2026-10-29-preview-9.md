# Orchard 0.1.0-preview.20261029.9

This preview accepts Progress on x64. The published-build catalog passes all
three sizes and four variants in Light and Dark, named read-only range and
passive focus behavior, live value/resize/template checks, and immediate value
changes with Windows animations already disabled. The matching independent
NuGet consumer compiles without warnings and passes 14 range states plus 24
native 150% no-clipping cases across both themes. No OS setting was changed.

## Accepted components

- Brand Mark
- Context Menu
- Kbd
- Label
- Loading Spinner
- Progress
- Separator
- Status Badge

The earlier seven components retain their `.8` x64 acceptance evidence; their
library implementation did not change in this preview. The fixed 112-entry
inventory now has **8 accepted** and 104 not yet accepted. These are entry
counts, not a completion percentage. Monitoring and Editorial remain fictional
local-data component demos. ARM64 catalogs and the independent package consumer
build, but native ARM64 runtime is unverified. Raster/pixel parity is not a
release gate.
