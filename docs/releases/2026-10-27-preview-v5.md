# Orchard component-library preview v5

`0.1.0-preview.20261027.5` is a [published prerelease](https://github.com/gaulatti/orchard/releases/tag/v0.1.0-preview.20261027.5)
of the component library. Its [NuGet package](https://github.com/gaulatti/orchard/releases/download/v0.1.0-preview.20261027.5/Gaulatti.Orchard.0.1.0-preview.20261027.5.nupkg)
(SHA-256 `367a9864c63927af56a6f0fc5590d7cc56649b1eaa37066b3f6950d266c09932`)
contains the Card padding precedence fix. A separate package-only x64 consumer
passed its focused Card Light/Dark and full native-input checks using the shared
dependency cache. A package-only ARM64 consumer compiled with zero warnings and
errors; it has not run on ARM64 hardware. See the [consumer](../evidence/card-padding-package-v5/checkpoint.json)
and [ARM64 build](../evidence/preview-v5-arm64-build/checkpoint.json) records.

The runnable catalog ZIPs are available for
[x64](https://github.com/gaulatti/orchard/releases/download/v0.1.0-preview.20261027.5/Orchard.Catalog.0.1.0-preview.20261027.5.win-x64.zip)
