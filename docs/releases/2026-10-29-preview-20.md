# Orchard 0.1.0-preview.20261029.20

This preview accepts Page Frame and Detail Layout on x64. Page Frame retains
caller content and focus through layout recipes; Detail Layout now changes its
side and ratio without rebuilding an unchanged caller template. Both pass the
five-check [component acceptance contract](../acceptance-contract.md):
applicable Light/Dark states, native keyboard/pointer/focus behavior, 150%
no-clipping, reduced motion, and independent package-consumer compilation.
Each passes 16 native 150% cases in an independent consumer. Neither layout
defines animation or transition; focused catalog behavior passes with animation
effects disabled. No OS settings were changed.

runtime is unverified. Raster/pixel parity is not a release gate.
