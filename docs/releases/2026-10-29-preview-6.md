# Orchard 0.1.0-preview.20261029.6

This preview adds Brand Mark to the accepted x64 components. The current
package passes its Light/Dark states, passive input/focus behavior, 150%
no-clipping, static reduced-motion behavior and independent consumer build.
Eyebrow remains unaccepted: rich content does not inherit uppercase casing,
and native 150% no-clipping is unverified.

## Accepted components

- **Brand Mark** — 37 Light/Dark states, decorative input/focus behavior, 150%
  no-clipping at four sizes in both themes, static reduced-motion behavior and
  x64 package-consumer compilation pass.
- **Context Menu** — Light/Dark states, keyboard/pointer/focus, 150%
  no-clipping, reduced motion and x64 package-consumer compilation pass.
- **Kbd** — Light/Dark states, passive input/focus behavior, 150% no-clipping,
  static reduced-motion behavior and x64 package-consumer compilation pass.
- **Separator** — Light/Dark states, passive input/focus behavior, 150%
  no-clipping, static reduced-motion behavior and x64 package-consumer
  compilation pass.
- **Status Badge** — Light/Dark states, display-only focus behavior, 150%
  no-clipping, static reduced-motion behavior and x64 package-consumer
  compilation pass.

The fixed inventory has 112 entries started: **5 accepted** and 107 not yet
accepted. These are entry counts, not a completion percentage. Monitoring and
Editorial remain fictional component demos. ARM64 is build-only, with runtime
unverified. Raster/pixel parity is not an acceptance gate.

## Validation and artifacts

- The library source is unchanged from preview `.4`, where 498 library tests
  and 10 text tests passed.
- The independent x64 package consumer compiles with zero warnings against
  this exact package (SHA-256
  `7f65b2f0fde7c5a4720ca0488c50067aa3d3fc6b31b488c313d2a84a27291698`).
- Brand Mark's package fixture passes 37 states, zero focus/activation, and
  eight native 150% bounds checks with inspected Light/Dark captures. Its
  package, consumer and x64 catalog share Orchard DLL SHA-256
  `9631e643af1ea1f7de69680dc500064483a00809450ac41409e62a1748bb91f0`.
- x64 and ARM64 catalog builds and archive integrity are checked. The x64
  archive DLL matches the package and consumer DLL; the x64 catalog hidden
  runtime probe passes. The ARM64 catalog runtime is unverified.
- GitHub Actions are not triggered by this release.
