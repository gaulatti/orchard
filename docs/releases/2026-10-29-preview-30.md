# Orchard 0.1.0-preview.20261029.30

This preview adds Brand Lockup and Dialog Close Button to the x64 accepted
list. Both passed applicable Light/Dark states, native pointer/keyboard/focus,
150% layout without clipping, reduced motion, and independent NuGet consumer
compilation. Brand Lockup's catalog fixture now changes the actual theme-owning
root when it checks live theme inheritance.

These are entry counts, not a completion percentage. Monitoring and Editorial
remain fictional local-data component demos. ARM64 is build-only; native ARM64
runtime is unverified. Raster/pixel parity is not a release gate.
