# Orchard 0.1.0-preview.20261029.12

This preview adds Section Header to the accepted x64 components. The published
x64 catalog renders its applicable states in Light and Dark and passes physical
forward/reverse Tab traversal around the passive heading. The independent NuGet
consumer compiles and runs, including sixteen native 150% no-clipping cases in
both themes. Section Header defines no animation or transition and also renders
with Windows animations disabled. No OS setting was changed.

## Accepted components

- Brand Mark
- Context Menu
- Error State
- Icon Badge
- Kbd
- Label
- Loading Spinner
- Progress
- Section Header
- Separator
- Status Badge

The fixed 112-entry inventory has **11 accepted** and 101 not yet accepted.
These are entry counts, not a completion percentage. Monitoring and Editorial
remain fictional local-data component demos. ARM64 catalog and independent
consumer builds pass; native ARM64 runtime is unverified. Raster/pixel parity
is not a release gate.
