## X64 acceptance and package verification

The exact .87 package-matching x64 catalog passed 41 Light and 41 Dark Hero Carousel states and 34 behavior contracts. Earlier focused physical x64 package/catalog runs verified owning-window arrow keys, native-editor exclusion, inactive-slide Tab/Enter/focus and original-item pointer clicks in both themes. Hero control, theme and catalog fixture source have not changed since those runs, so the focused observations are reused. The independent .87 package consumer compiled and passed four native 150% Light/Dark 700/1000-DIP cases without clipped host, slide, arrows, title or action; slide opacity stayed static with Windows animations disabled. Earlier accepted components retain their five-check inventory records.

The 498 repository tests passed for .86; the Hero implementation source is unchanged in .87. The exact .87 catalog's fictional Monitoring and Editorial demos passed 72 hidden checks. The ARM64 catalog built and an independent ARM64 consumer compiled; ARM64 runtime remains unverified. The full default x64 consumer runtime sweep was not run for this release. The earlier physical-test processes closed, but their exit codes were not captured.
