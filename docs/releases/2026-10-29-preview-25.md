# Orchard 0.1.0-preview.20261029.25

This preview accepts Button and Button Group on x64. Both passed Light and Dark
states, physical keyboard/pointer/focus actions, four native 150% scaling cases,
reduced-motion behavior, and independent NuGet consumer compilation. Button's
loading spinner stops when animations are disabled; Button Group has static
behavior. The matching extracted catalog passed both focused input routes.

The fixed 112-entry inventory has **28 accepted** and 84 not yet accepted.
These are entry counts, not a completion percentage. Monitoring and Editorial
remain fictional local-data component demos. ARM64 is build-only; native ARM64
runtime is unverified. Raster/pixel parity is not a release gate.
