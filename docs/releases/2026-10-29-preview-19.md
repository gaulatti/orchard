# Orchard 0.1.0-preview.20261029.19

This preview accepts Feed Grid on x64. The matching catalog passed 144
Light/Dark layout states and native child pointer, keyboard and focus behavior
through resize, collection moves and remount. The independent NuGet consumer
compiled and ran, including 16 native 150% no-clipping cases across both themes,
narrow/wide viewports and normal/wrapped/collapsed/empty states. Feed Grid has no
animation or transition; its static behavior passed with animation effects
disabled. No OS setting was changed.

## Accepted components

- Brand Mark
- Card
- Context Menu
- Dashboard Grid
- Dashboard Section
- Empty
- Error State
- Feed Grid
- Icon Badge
- Kbd
- Label
- Loading Spinner
- Metric
- Page Header
- Progress
- Progress Stack
- Section Header
- Separator
- Sparkline
- Status Badge

The fixed 112-entry inventory has **20 accepted** and 92 not yet accepted.
These are entry counts, not a completion percentage. Monitoring and Editorial
remain fictional local-data component demos. ARM64 catalog and independent
consumer builds pass; native ARM64 runtime is unverified. Raster/pixel parity
is not a release gate.
