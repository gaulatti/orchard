# Orchard 0.1.0-preview.20261029.24

This preview accepts Stat Card on x64. The matching extracted catalog passed
Light and Dark layout, content, overflow, typography, native keyboard/focus,
and physical pointer-click checks. An independent NuGet consumer compiled and
ran against the package; its native 150% fixture passed four Light/Dark
narrow/wide Stat Card cases. Stat Card has no animation or transition, and its
static states passed while Windows animations were disabled.

The fixed 112-entry inventory has **26 accepted** and 86 not yet accepted.
These are entry counts, not a completion percentage. Monitoring and Editorial
remain fictional local-data component demos. ARM64 is build-only; native ARM64
runtime is unverified. Raster/pixel parity is not a release gate.
