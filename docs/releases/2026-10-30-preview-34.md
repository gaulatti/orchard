# Orchard 0.1.0-preview.20261030.34

This preview adds Activity Item and Data List to the x64 accepted list. Each
passes the five component checks: applicable Light/Dark states, keyboard,
pointer and focus behavior, native 150% no-clipping, reduced motion, and
independent package-consumer compilation. The fixed 112-entry inventory has
**41 accepted** and 71 not yet accepted. Monitoring and Editorial remain
fictional local-data component demos.
