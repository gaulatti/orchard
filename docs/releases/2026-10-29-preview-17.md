# Orchard 0.1.0-preview.20261029.17

This preview accepts Progress Stack on x64. The matching catalog passed 140
Light/Dark states across ordinary and reduced motion, twelve lifecycle phases,
passive keyboard/focus behavior, and physical pointer entry on the original
segments. The independent NuGet consumer compiled and ran, including sixteen
native 150% no-clipping cases across both themes and narrow/wide viewports.
Progress Stack defines no animation or transition; no OS setting was changed.
The independent consumer's Column Toggle fixture now waits for its native
checkboxes to load before invoking them, addressing an observed cold-start
timing failure.

- Brand Mark

- Dashboard Section
- Empty
- Error State
- Icon Badge
- Kbd
- Label
- Loading Spinner
- Page Header
- Progress
- Progress Stack
- Section Header
- Separator
- Status Badge

The fixed 112-entry inventory has **17 accepted** and 95 not yet accepted.
These are entry counts, not a completion percentage. Monitoring and Editorial
remain fictional local-data component demos. ARM64 catalog and independent
consumer builds pass; native ARM64 runtime is unverified. Raster/pixel parity
is not a release gate.
