# Orchard 0.1.0-preview.20261029.7

This preview adds Loading Spinner to the accepted x64 components. The current
package and matching catalog verify its Light/Dark sizes and theme states,
passive input/focus behavior, native 150% no-clipping, static reduced-motion
behavior and independent consumer compilation. Eyebrow's wrapped plain and rich
states now pass native 150% no-clipping, but rich content still lacks inherited
uppercase casing; Eyebrow remains unaccepted.

## Accepted components

- **Brand Mark** — Light/Dark states, decorative input/focus behavior, 150%
  no-clipping, static reduced-motion behavior and package-consumer compilation.
- **Context Menu** — Light/Dark states, keyboard/pointer/focus, 150%
  no-clipping, reduced motion and package-consumer compilation.
- **Kbd** — Light/Dark states, passive input/focus behavior, 150% no-clipping,
  static reduced-motion behavior and package-consumer compilation.
- **Loading Spinner** — Light/Dark size/theme states, passive input/focus,
  150% no-clipping, static reduced-motion behavior and package-consumer
  compilation.
- **Separator** — Light/Dark states, passive input/focus behavior, 150%
  no-clipping, static reduced-motion behavior and package-consumer compilation.
- **Status Badge** — Light/Dark states, display-only focus behavior, 150%
  no-clipping, static reduced-motion behavior and package-consumer compilation.

The fixed inventory has 112 entries started: **6 accepted** and 106 not yet
accepted. These are entry counts, not a completion percentage. Monitoring and
Editorial remain fictional component demos. ARM64 is build-only and runtime
unverified. Raster/pixel parity is not an acceptance gate.

## Validation and artifacts

- The library source is unchanged from preview `.4`, where 498 library tests
  and 10 text tests passed.
- The independent x64 package consumer compiles with zero warnings against
  this exact package (SHA-256
  `773f8138d34d62367e784ccb3eee7572fd10105c00a129b6bf79222685e6ee44`).
- Loading Spinner passes the matching x64 catalog's Light/Dark sizes, theme
  brushes, constrained row and reduced-motion checks. The 150% package DLL
  capture shows the large ring inside its bounds in both themes.
- Eyebrow passes four native 150% wrapped-content bounds checks in Light/Dark;
  rich-content casing remains a failed state check.
- x64 and ARM64 catalogs build and their archive contents are verified.
  The package, consumer and x64 catalog share Orchard DLL SHA-256
  `ca9badea7a1f383c66d2e9e9d60814464efdb03a5d693ec9df8c9cd85cf35bdc`.
  ARM64 runtime is unverified. GitHub Actions are not triggered by this release.
