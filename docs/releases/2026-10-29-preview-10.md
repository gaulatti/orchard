# Orchard 0.1.0-preview.20261029.10

This preview accepts Error State on x64. The published-build catalog passes
seven specimens in both Light and Dark, including physical pointer and Space
retry, native focus, disabled command behavior, and live content changes. The
matching independent NuGet consumer compiles and runs without warnings. Its
native 150% scale fixture passes fourteen specimen/theme cases with visible
content inside each control. Error State is static and the non-loading retry
button has no active spinner; the catalog passed with Windows animations
already disabled. No OS setting was changed.

## Accepted components

- Brand Mark
- Context Menu
- Error State
- Kbd
- Label
- Loading Spinner
- Progress
- Separator
- Status Badge

The fixed 112-entry inventory has **9 accepted** and 103 not yet accepted.
These are entry counts, not a completion percentage. Monitoring and Editorial
remain fictional local-data component demos. ARM64 catalog and independent
consumer builds pass; native ARM64 runtime is unverified. Raster/pixel parity
is not a release gate.
