# Orchard 0.1.0-preview.20261029.5

This preview accepts the display-only Kbd component under the 2026-10-29 x64
milestone. Its single keycap, key combinations, caller content and metadata
render in Light and Dark; isolated 150% captures show no clipping. It has no
shortcut registration, command, tab stop or animation. The library source is
unchanged from the previous preview.

## Accepted components

- **Context Menu** — Light/Dark states, keyboard/pointer/focus, 150% no-clipping,
  reduced motion and x64 package-consumer compilation pass.
- **Kbd** — Light/Dark states, passive input/focus behavior, 150% no-clipping,
  static reduced-motion behavior and x64 package-consumer compilation pass.
- **Separator** — Light/Dark states, passive input/focus behavior, 150%
  no-clipping, static reduced-motion behavior and x64 package-consumer
  compilation pass.
- **Status Badge** — Light/Dark states, display-only focus behavior, 150%
  no-clipping, static reduced-motion behavior and x64 package-consumer
  compilation pass.

The fixed inventory has 112 entries started: **4 accepted** and 108 not yet
accepted. These are entry counts, not a completion percentage. Monitoring and
Editorial remain fictional component demos.
