# Orchard 0.1.0-preview.20261029.13

This preview accepts Page Header on x64. The published catalog passes sixteen
Light/Dark states, including narrow and wide viewports, wrapped and empty
content, RTL, Back pointer/Space activation, disabled commands and retained
focus. The independent NuGet consumer compiles and runs, including 22 native
150% no-clipping cases across both themes and viewport modes. Page Header and
its Back style define no animation or transition; the catalog passed with
Windows animations disabled. No OS setting was changed.

## Accepted components

- Brand Mark
- Context Menu
- Error State
- Icon Badge
- Kbd
- Label
- Loading Spinner
- Page Header
- Progress
- Section Header
- Separator
- Status Badge

The fixed 112-entry inventory has **12 accepted** and 100 not yet accepted.
These are entry counts, not a completion percentage. Monitoring and Editorial
remain fictional local-data component demos. ARM64 catalog and independent
consumer builds pass; native ARM64 runtime is unverified. Raster/pixel parity
is not a release gate.
