# Orchard 0.1.0-preview.20261029.4

This preview adds a 150% scaling repair for caller-constrained Context Menus.
Long menu labels now wrap within the native item in Light and Dark while
single-line items keep their existing minimum height. The modal-owned native
item remains clickable and invokes the caller's action.

## Accepted components

- **Context Menu** — Light/Dark states, keyboard/pointer/focus, 150% scaling
  without clipping, reduced motion, and x64 package-consumer compilation pass.
- **Separator** — Light/Dark states, passive input/focus behavior, 150% scaling
  without clipping, static reduced-motion behavior, and x64 package-consumer
  compilation pass.
- **Status Badge** — Light/Dark states, display-only focus behavior, 150%
  scaling without clipping, static reduced-motion behavior, and x64
  package-consumer compilation pass.

The fixed inventory has 112 entries started: **3 accepted** and 109 not yet
accepted. These are entry counts, not a completion percentage. Monitoring and
Editorial remain fictional component demos.
