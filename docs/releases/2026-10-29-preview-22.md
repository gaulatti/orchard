# Orchard 0.1.0-preview.20261029.22

This preview accepts Footer on x64. The exact packaged DLL renders 64 Footer
Light/Dark catalog states and passes native pointer, Enter and focus checks in
both themes. Four narrow/wide Light/Dark layouts keep visible Footer content
within bounds at 150% scale. With Windows animations disabled, pointer hover
changes ink immediately and stays stable; no OS setting was changed. An
independent x64 NuGet consumer compiled and ran against this package.

These are entry counts, not a completion percentage. Monitoring and Editorial
remain fictional local-data component demos. ARM64 is build-only; native ARM64
runtime is unverified. Raster/pixel parity is not a release gate.
