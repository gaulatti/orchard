# Orchard component-library preview v7 — crash fix and x64/ARM64 catalogs

`0.1.0-preview.20261027.7` is a [published prerelease](https://github.com/gaulatti/orchard/releases/tag/v0.1.0-preview.20261027.7)
of the reusable C# / WinUI 3 component library. Its
[NuGet package](https://github.com/gaulatti/orchard/releases/download/v0.1.0-preview.20261027.7/Gaulatti.Orchard.0.1.0-preview.20261027.7.nupkg)
has SHA-256 `5be14cb1dc7c52bee1fece0ca8cf1c74a86bb5f3b6dd2bd20294d67d5395cf1d`.
GitHub reports the same digest for the uploaded asset. The release tag points
to source commit `780c313e919e2fab1c1f3a856b4c19add1c07ffd`.

This version fixes the v5 consumer crashes on routed hover over Theme Toggle's
default tooltip and on normal window close while the Attention pointer observer
sees a torn-down WinUI content island. The default tooltip is per-instance,
including when a generated style is shared with another toggle.

The exact package passed a separate x64 package-reference consumer. Accepted
and rejected pointer, Space and Enter paths, visible tooltip update, clean
window close, and full Light/Dark consumer checks passed. The hidden native
diagnostic passed 116 normal states and 42 ownership/lifecycle checks. x64 and
ARM64 library builds completed without warnings. The
[checkpoint](../evidence/theme-toggle-v7-lifecycle-v1/checkpoint.json) retains
the reports, hashes and screenshots.

The [x64 runnable catalog ZIP](https://github.com/gaulatti/orchard/releases/download/v0.1.0-preview.20261027.7/Orchard.Catalog.0.1.0-preview.20261027.7.win-x64.zip)
has SHA-256 `def4212845931f860ef2a1f4b92ce5e9c362ce4500e4938d47d4c27f3d66b0e6`;
GitHub reports the same digest. It contains the exact DLL from the released
NuGet package. All 821 archive entries and extracted file hashes passed,
including 114 compiled catalog XAML fixtures. The extracted application passed
its 653-resource audit, physical Monitoring review/update in Light, and
Editorial search in Dark and edit in Light. The same built catalog also passed
Monitoring in both themes and Editorial search/edit in the complementary
themes. The [catalog checkpoint](../evidence/catalog-v7-x64/checkpoint.json)
records the provenance, reports, and limits. Desktop demo probes confirmed
process exit but did not record exit codes; the extracted resource probe exited
zero.

The [published catalog Theme Toggle check](../evidence/theme-toggle-v7-catalog-foreground-v1/checkpoint.json)
also passes physical pointer, Space and Enter requests through the three
consumer-owned modes in system Dark and explicit Light. The catalog window
closed, but this focused check did not capture its exit code or establish the
full visual, motion, scaling and ARM64 runtime contract.

The extracted x64 archive also passed 72 hidden Monitoring/Editorial demo
checks, 589 isolation guards and 25 damaged-receipt rejections in Light and
Dark, including fictional Editorial relation ordering and local save. The
[workspace checkpoint](../evidence/catalog-v7-workspaces-hidden-v1/checkpoint.json)
records the exact catalog and library bytes. Visible relationship input was
previously checked in an unchanged source fixture; full published-archive input,
visual, scaling and native ARM64 acceptance remain open.

normal builds embed the current Git revision in assembly metadata and do not
reproduce the earlier package's byte hash.
