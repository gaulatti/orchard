## X64 acceptance and package verification

Alert Dialog passes the five milestone checks on the exact .70 x64 package and
extracted catalog. The independent consumer passes 56 Light/Dark state cases.
Physical pointer confirmation, Space reopening, Escape cancellation and focus
return pass in both themes. The package consumer passes four native 150% layouts
at 420/600 DIP without clipping. With animations disabled, the open surface
reaches its reduced-motion endpoint. The consumer compiles and runs. The
extracted catalog passes 72 fictional Monitoring and Editorial demo checks.
The library implementation is unchanged; this release adds focused acceptance
fixtures.

The x64 catalog archive is byte-verified and contains the same library DLL as
the NuGet package. ARM64 builds and its independent consumer compiles; ARM64
runtime is unverified.
