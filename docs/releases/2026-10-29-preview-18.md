# Orchard 0.1.0-preview.20261029.18

This preview accepts Metric and Sparkline on x64. Metric passed 340 format and
state cases per theme plus live rich-slot keyboard, pointer and focus checks.
Sparkline passed 18 source states per theme plus native pointer, keyboard,
focus and data-mutation checks. Both controls have static rendering without
animation or transition and passed with animation effects disabled. The
independent package consumer passed 20 native 150% no-clipping cases for each
component across Light/Dark themes and narrow/wide viewports. No OS setting
was changed.

The fixed 112-entry inventory has **19 accepted** and 93 not yet accepted.
These are entry counts, not a completion percentage. Monitoring and Editorial
remain fictional local-data component demos. ARM64 catalog and independent
consumer builds pass; native ARM64 runtime is unverified. Raster/pixel parity
is not a release gate.
