# Orchard 0.1.0-preview.20261029.15

This preview accepts Card on x64. The matching catalog passes all five Card
variants and four padding choices in Light and Dark. Physical Tab, reverse Tab,
Space and pointer input reach an original consumer child action; Card itself
adds no keyboard stop. The independent NuGet consumer compiles and runs, and
passes twenty native 150% no-clipping cases across both themes, five variants
and narrow/wide viewports. Card has no animation or transition and passed with
Windows animations disabled; no OS setting was changed.

## Accepted components

- Brand Mark
- Card
- Context Menu
- Dashboard Grid
- Dashboard Section
- Error State
- Icon Badge
- Kbd
- Label
- Loading Spinner
- Page Header
- Progress
- Section Header
- Separator
- Status Badge

The fixed 112-entry inventory has **15 accepted** and 97 not yet accepted.
These are entry counts, not a completion percentage. Monitoring and Editorial
remain fictional local-data component demos. ARM64 catalog and independent
consumer builds pass; native ARM64 runtime is unverified. Raster/pixel parity
is not a release gate.
