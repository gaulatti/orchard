# Orchard 0.1.0-preview.20261029.14

This preview accepts Dashboard Grid and Dashboard Section on x64. The published
catalog passes 96 Grid and 50 Section captured Light/Dark cases, with physical
keyboard, pointer and focus checks through original consumer child actions.
The independent NuGet consumer compiles and runs, including eight Grid and
twelve Section native 150% no-clipping cases across both themes. Section cases
include its intentional painted action overflow. Both layouts are static and
passed with animations disabled; no OS setting was changed.

## Accepted components

- Brand Mark
- Context Menu
- Dashboard Grid
- Dashboard Section
- Error State
- Icon Badge
- Kbd
- Label
- Loading Spinner
- Page Header
- Progress
- Section Header
- Separator
- Status Badge

The fixed 112-entry inventory has **14 accepted** and 98 not yet accepted.
These are entry counts, not a completion percentage. Monitoring and Editorial
remain fictional local-data component demos. ARM64 catalog and independent
consumer builds pass; native ARM64 runtime is unverified. Raster/pixel parity
is not a release gate.
