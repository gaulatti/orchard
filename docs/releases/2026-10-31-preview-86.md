## X64 acceptance and package verification

The exact .86 package-matching x64 catalog passed 15 Light and 15 Dark Menubar states and 28 behavior contracts. The clean catalog passed physical Down/Enter focus and action invocation plus pointer root/action activation in both themes. A focus handoff now waits for popup rows to load before moving keyboard focus. The independent package consumer compiled and passed four native 150% Light/Dark 700/1000-DIP cases without clipped triggers, popup or rows; popup geometry and opacity stayed static with Windows animations disabled. Earlier accepted components retain their five-check inventory records.

All 498 repository tests passed. An initial fictional-demo run under concurrent build load stopped at a Dark Editorial load assertion; an isolated rerun of the exact .86 catalog passed all 72 hidden Monitoring and Editorial checks. The ARM64 catalog built and an independent ARM64 consumer compiled; ARM64 runtime remains unverified. The full default x64 consumer runtime sweep was not run for this release.
