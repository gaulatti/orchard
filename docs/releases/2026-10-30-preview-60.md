## Validation and artifacts

- The published .59 x64 catalog, with unchanged Auth Shell library and theme
  source, passed 104 Light/Dark states and 24 contracts, plus 132 container and
  root-size states and 32 contracts. Both independent audits passed.
- The extracted .60 x64 catalog passed physical Tab, Space and pointer input in
  Light and Dark, preserving the original caller input and content across a
  centered-to-split layout change. The initial smoke wrapper lacked its required
  catalog captures; adding them and rerunning passed. There was no component
  input failure.
- The independent .60 package consumer compiled and passed its generic x64
  runtime check. Four native 150% Auth Shell layouts passed across Light/Dark
  and centered/split modes; visible slot and caller text stayed within bounds,
  and the static layout stayed settled with Windows animations already disabled.
- The x64 catalog ZIP was stream-verified across 664 files. Its extracted
  Orchard.dll matched the NuGet package; the extracted fictional Monitoring and
  Editorial demos passed 72 isolated checks.
- The ARM64 catalog built and its ZIP was stream-verified across 660 files. The
  independent ARM64 package consumer compiled. ARM64 runtime is unverified.
- The library implementation is unchanged. The previously passed 498 portable
  and 10 Windows text tests are reused; .60 changes catalog and package-consumer
  acceptance fixtures and documentation only.
