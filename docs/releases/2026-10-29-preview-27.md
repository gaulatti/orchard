# Orchard 0.1.0-preview.20261029.27

This preview accepts Tooltip on x64. The matching extracted catalog passed
Light and Dark states across all four placements, long and templated content,
collision flips, and immediate reduced-motion dismissal. Physical hover,
pointer leave, Tab/Shift+Tab focus and Escape passed in both themes. An
independent NuGet consumer compiled and ran against the package; its native
150% fixture passed 16 narrow/wide placement cases without clipping.

runtime is unverified. Raster/pixel parity is not a release gate.
