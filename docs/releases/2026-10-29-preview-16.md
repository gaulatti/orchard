# Orchard 0.1.0-preview.20261029.16

This preview accepts Empty on x64. The matching catalog passed 120 Light/Dark
state frames across ordinary and reduced motion, twelve lifecycle phases, and
focused physical pointer and keyboard behavior for the consumer-owned action.
The independent NuGet consumer compiled and ran. It passed twelve native 150%
no-clipping cases across both themes and narrow/wide viewports. Empty defines no
animation or transition; no OS setting was changed.

## Accepted components

- Brand Mark
- Card
- Context Menu
- Dashboard Grid
- Dashboard Section
- Empty
- Error State
- Icon Badge
- Kbd
- Label
- Loading Spinner
- Page Header
- Progress
- Section Header
- Separator
- Status Badge

The fixed 112-entry inventory has **16 accepted** and 96 not yet accepted.
These are entry counts, not a completion percentage. Monitoring and Editorial
remain fictional local-data component demos. ARM64 catalog and independent
consumer builds pass; native ARM64 runtime is unverified. Raster/pixel parity
is not a release gate.
