# Orchard 0.1.0-preview.20261029.8

This preview accepts Label on x64. Its plain, error-styled, disabled, empty,
wrapped, Unicode, template, rich and linked states pass the focused Light/Dark
catalog fixture. The independent NuGet consumer compiles without warnings and
passes 26 Light/Dark association cases. Its native 150% island verifies eight
plain, rich, disabled and empty bounds checks across both themes. Label is
static and has no animation or transition. Physical pointer and keyboard
behavior passed on the earlier published v7 consumer; the Label control,
template and catalog fixture have not changed since that release. Two current
foreground-launch attempts stopped before sending input because Windows did
not give the consumer focus. They are recorded as harness failures.

## Accepted components

- Brand Mark
- Context Menu
- Kbd
- Label
- Loading Spinner
- Separator
- Status Badge

All seven pass the milestone's five x64 checks: applicable Light/Dark states,
keyboard/pointer/focus, no clipping at native 150% scale, reduced motion, and
independent package-consumer compilation. The fixed 112-entry inventory has
**7 accepted** and 105 not yet accepted. These are entry counts, not a
completion percentage. Monitoring and Editorial remain fictional local-data
component demos. ARM64 catalogs build, but native ARM64 runtime is unverified.
Raster/pixel parity is not a release gate.
